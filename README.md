# The CFIHOS ontology

This repository provides the resources generated in the development of the CFHIOS ontology.

This ontology has been generated from the [CFHIOS specification in Excel format](./data/CORE-CFIHOS-V2.0-excel-FINAL.xlsx).

We also provide a [description of the ontology generated](./ontology/README.md), which has been aligned with the [Industrial Data Ontology](https://rds.posccaesar.org/ontology/lis14/ont/core/).

The ontology has been generated by applying a [script](./code/README.md) which is also provided in this repository.

We also provide a set of [competency questions (CQ)](./test/CFIHOS_CQ.docx). This file contains CQs, the SPARQL query that solves the corresponding CQ, and the result provided. This can be tested by querying the ontology in Protégé by using the SPARQL tab.

Finally, [an example of data representation](./test/README.md) using the CFHIOS ontology is provided
