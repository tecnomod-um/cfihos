
# Testing the CFHIOS ontology

The testing of the CFHIOS ontology is done as follows:

* We provide a [set of competency questions (CQ)](CFIHOS_CQ.docx). This file contains CQs, the SPARQL query that solves the corresponding CQ, and the result provided. This can be tested by querying the ontology in Protégé by using the SPARQL tab.

* We provide the modeling according to the ontology of the following sample data in an [OWL file](example.owl).
